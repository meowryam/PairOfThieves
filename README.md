#  Pair of Thieves



\### Two thieves. One vault. A whole lot of data structures.



\*\*Pair of Thieves\*\* is a DSA-based puzzle game where players break into the mysterious Living Vault by solving algorithmic challenges, manipulating data structures, and escaping before the alarm goes off.



\##  Acts



\-  \*\*Act 1:\*\* Binary Trees

\-  \*\*Act 2:\*\* Binary Search Trees

\-  \*\*Act 3:\*\* AVL Trees

\-  \*\*Act 4:\*\* Max Heaps \& Heap Sort
